# Stage 2 — Download

**What:** Download the selected T1w/resting fMRI images and ADNI Study Files.

**Output:** Image archives, collection CSVs, metadata and clinical/QC/NFQ CSVs.

## Run

1. Sign in to [LONI IDA](https://ida.loni.usc.edu/login.jsp) with approved ADNI access.
2. Create and download the reviewed T1w/resting-fMRI collection; retain its image IDs and collection CSV.
3. Download the matching metadata and Study Files, including clinical, MRI QC, NFQ and deletion records.
4. Store everything outside the repository, following the [data layout](../../06_docs/data_preparation.md).

This is a manual portal step; no downloader is included.
