# Stage 1 — ADNI access

**What:** Request permission to use ADNI data.

**Output:** An approved ADNI account.

## Run

1. Register at [LONI IDA](https://ida.loni.usc.edu/login.jsp).
2. Submit the [ADNI access application](https://ida.loni.usc.edu/collaboration/access/appApply.jsp?project=ADNI).
3. After approval, continue to [download](../s2_download/README.md).

This is a manual portal step; no local code is required.
