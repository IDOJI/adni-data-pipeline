# Stage 1 — ADNI access

**What:** Request permission to use ADNI data.

**Output:** An approved ADNI account.

## Run

Use your own institutional details in the application and retain the approval for the project and collaborators who will use the images.

1. Register at [LONI IDA](https://ida.loni.usc.edu/login.jsp).
2. Submit the [ADNI access application](https://ida.loni.usc.edu/collaboration/access/appApply.jsp?project=ADNI).
3. After approval, continue to [download](../../02-bids/download/README.md).

This is a manual portal step; no local code is required.

## Evidence and limits

Sources: [ADNI FAQ answers](https://adni.loni.usc.edu/help-faqs/faqs/). The [Stage 1 evidence record](../../support/docs/stage_evidence.md#stage-1) identifies the relevant answer/section and separates direct evidence from project policy and engineering controls.
